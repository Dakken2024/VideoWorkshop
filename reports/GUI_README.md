# Video Creator GUI 使用说明

## 简介
这是一个基于Python Tkinter的图形界面应用程序，用于简化视频创作流程，特别适用于视频号内容创作者。

## 功能特点

### 1. 内容管理
- **标题设置**：输入视频标题，自动转换为文件目录名
- **Markdown编辑**：支持Markdown格式的内容编辑
- **文件导入**：可以直接加载 `.md` 文件

### 2. 脚本管理
- **JSON脚本编辑**：可视化编辑视频脚本
- **脚本验证**：实时验证JSON格式正确性
- **文件操作**：支持加载和保存脚本文件

### 3. 图片生成
- **批量图片生成**：根据脚本自动生成所有场景图片
- **实时日志显示**：显示图片生成进度和状态
- **文件组织**：自动按日期和标题组织输出文件

### 4. 视频生成
- **一键生成**：完整视频生成流程
- **进度跟踪**：实时显示生成进度
- **输出管理**：自动整理生成的文件

## 使用流程

### 1. 准备工作
```
项目目录/
├── auto_video_maker.py     # 核心视频生成脚本
├── simple_video_gui.py     # GUI应用程序
├── scripts.json           # 脚本文件（可选）
└── *.md                   # 内容文件（可选）
```

### 2. 启动GUI
```bash
python simple_video_gui.py
```

### 3. 创建视频项目

#### 步骤1：设置项目基本信息
- 在"视频标题"输入框中输入视频标题
- 可以通过"加载Markdown"按钮导入现有的内容文件

#### 步骤2：编辑内容
- 在"视频内容"区域编辑Markdown格式的内容
- 内容将用于生成视频脚本

#### 步骤3：配置脚本
- 在"视频脚本"区域编辑JSON格式的脚本
- 或通过"加载脚本"按钮导入现有脚本
- 使用"验证JSON"按钮检查脚本格式

#### 步骤4：生成图片
- 点击"生成图片"按钮
- 查看日志区域了解生成进度
- 图片将保存到 `./output/YYYYMM/标题/` 目录

#### 步骤5：生成视频
- 点击"生成视频"按钮
- 完整的视频生成流程将自动执行
- 最终视频保存在同一输出目录

### 4. 文件输出结构
```
./output/
└── 202602/                           # 年月目录
    └── shi_jie_shang_di_yi_wei_.../   # 拼音目录名（中文标题自动转拼音）
        ├── voiceover.mp3              # 合成音频
        ├── scene_0.jpg                # 场景图片
        ├── scene_1.jpg
        ├── ...
        ├── scripts.json               # 脚本文件
        └── shi_jie_shang_di_yi_....mp4 # 最终视频
```

> 💡 **目录命名规则**：中文标题会自动转换为拼音格式，如"世界上第一位程序员"→"shi_jie_shang_di_yi_wei_cheng_xu_yuan"，确保目录名兼容性和可读性。

## 技术细节

### 依赖库
- `tkinter` - GUI界面（Python内置）
- `json` - JSON处理（Python内置）
- `subprocess` - 调用外部脚本
- `threading` - 多线程处理
- `pypinyin` - 中文转拼音（需要安装）

### 与auto_video_maker.py的集成
GUI通过以下方式与核心脚本集成：
1. **文件共享**：使用相同的 `scripts.json` 文件
2. **进程调用**：通过 `subprocess` 调用核心脚本
3. **实时日志**：捕获并显示脚本输出

### 异常处理
- 所有文件操作都有异常处理
- 网络请求失败有重试机制
- 用户友好的错误提示对话框

## 注意事项

1. **环境要求**：确保已安装所有必要的依赖库
2. **网络连接**：图片生成需要网络连接
3. **磁盘空间**：确保有足够的磁盘空间存储生成的文件
4. **权限问题**：确保对输出目录有写入权限

## 故障排除

### 常见问题

1. **GUI无法启动**
   - 检查Python版本（建议3.7+）
   - 确认tkinter库已安装

2. **图片生成失败**
   - 检查网络连接
   - 确认API服务可用性
   - 查看日志了解具体错误

3. **视频生成卡住**
   - 检查系统资源使用情况
   - 确认输出目录有足够空间
   - 查看详细日志信息

### 日志查看
- 所有操作都会记录到"运行日志"区域
- 可以通过"保存日志"按钮导出日志文件
- 日志包含时间戳，便于问题追踪
