## 一、概述

### 1.1 系统架构

本系统采用模块化架构，所有优化代码部署在 `video_gen/` 目录下，与原有生产环境代码完全隔离。

```
VideoWorkshop/
├── video_gen/                    # 优化版代码（新系统）
│   ├── cli.py                    # 命令行入口
│   ├── workflow.py               # 精简工作流（推荐）
│   ├── subtitle_importer.py      # 字幕自动导入器
│   ├── config.py                 # 集中配置管理
│   ├── deploy.py                 # 部署工具
│   ├── core/                     # 核心引擎
│   ├── audio/                    # 音频生成
│   ├── image/                    # 图片生成
│   ├── video/                    # 视频合成+字幕
│   ├── utils/                    # 工具模块
│   └── tests/                    # 测试套件
│
├── auto_video_maker.py           # 原有系统（未修改）
├── video_creator_gui.py          # 原有GUI（未修改）
├── ...其他原有文件...               # 保留原状
```

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 一键视频生成 | 从脚本 JSON 自动完成音频、图片、视频合成 |
| 字幕自动导入 | 为已有视频自动生成并嵌入字幕 |
| GPU 加速检测 | 自动检测 GPU 编码器，不可用时回退到 CPU |
| 断点续传 | 中断后可从已有目录继续生成 |
| 系统诊断 | 一键检测依赖和运行环境 |

## 三、标准工作流程

### 3.1 快速开始（推荐）

**两步完成视频生成：**

**第一步**：准备脚本文件 `scripts.json`

```json
{
  "meta": {
    "title": "我的视频",
    "description": "视频描述"
  },
  "scenes": [
    {
      "scene_id": 1,
      "text": "这是第一段描述文字",
      "prompt": "图片生成提示词",
      "duration_sec": 5,
      "note": "场景说明"
    },
    {
      "scene_id": 2,
      "text": "这是第二段描述文字",
      "prompt": "图片生成提示词",
      "duration_sec": 5,
      "note": "场景说明"
    }
  ]
}
```

**第二步**：执行一键生成

```bash
# 方式一：使用精简工作流（推荐）
python -c "
from video_gen.workflow import quick_generate
result = quick_generate(script_path='scripts.json', title='我的视频')
print('成功!' if result['success'] else '失败:', result.get('errors'))
"

# 方式二：使用 CLI
python -m video_gen.cli generate -t "我的视频" -s scripts.json

# 方式三：分步执行
python -m video_gen.cli audio -s scripts.json -o ./output
python -m video_gen.cli images -s scripts.json -o ./output
python -m video_gen.cli compose -s scripts.json -a ./output/voiceover.mp3 -i ./output -o ./output
```

### 3.2 输出目录结构

```
output/
└── 202608/                          # 年月目录
    └── wo_de_shi_pin/               # 视频目录（拼音名）
        ├── scripts.json             # 脚本文件
        ├── voiceover.mp3            # 音频文件
        ├── scene_000.jpg            # 场景图片
        ├── scene_001.jpg
        ├── wo_de_shi_pin.mp4        # 最终视频（含字幕）
        ├── scene_audio_durations.json  # 音频时长信息
        └── generation_report.json   # 生成报告
```

### 3.3 断点续传

如果生成过程中断，可以从中断点继续：

```bash
python -c "
from video_gen.workflow import resume_generate
result = resume_generate(project_dir='output/202608/wo_de_shi_pin')
print('继续完成!' if result['success'] else '失败:', result.get('errors'))
"
```

系统会自动检测已有文件，跳过已完成的步骤。

## 四、字幕功能详解

### 4.1 字幕自动导入

为已有视频自动生成并嵌入字幕，解决原系统无字幕功能的问题。

```bash
# 基本用法
python -m video_gen.cli subtitles -v output.mp4 -s scripts.json

# 指定字幕格式
python -m video_gen.cli subtitles -v output.mp4 -s scripts.json --format ass

# 仅生成字幕文件，不嵌入视频
python -m video_gen.cli subtitles -v output.mp4 -s scripts.json --dry-run

# 使用独立字幕导入器
python video_gen/subtitle_importer.py -v output.mp4 -s scripts.json
```

### 4.2 字幕自动检测模式

```bash
# 自动检测视频所在目录的脚本文件
python video_gen/subtitle_importer.py -v output.mp4

# 自动检测目录中的视频和脚本
python video_gen/subtitle_importer.py -d output/202608/wo_de_shi_pin

# 批量导入目录下所有视频
python video_gen/subtitle_importer.py -d output/202608 --batch
```

### 4.3 字幕格式说明

| 格式 | 说明 | 优点 |
|------|------|------|
| SRT | 简单字幕格式 | 兼容性最好，所有播放器支持 |
| ASS | 高级字幕格式 | 支持字体样式、位置、动画 |

### 4.4 字幕时间轴对齐

字幕系统支持三种时间轴对齐方式，按优先级自动选择：

1. **精确时长**：加载 `scene_audio_durations.json` 中的精确场景时长
2. **视频检测**：通过 `ffprobe` 从视频文件提取时长
3. **按比例分配**：根据预设时长按比例分配音频总时长

## 五、CLI 命令参考

### 5.1 命令列表

| 命令 | 功能 | 示例 |
|------|------|------|
| `generate` | 完整视频生成 | `cli generate -t "标题" -s scripts.json` |
| `audio` | 仅生成音频 | `cli audio -s scripts.json -o ./output` |
| `images` | 仅生成图片 | `cli images -s scripts.json -o ./output` |
| `compose` | 合成视频 | `cli compose -s scripts.json -a audio.mp3 -i ./images -o ./output` |
| `subtitles` | 字幕导入 | `cli subtitles -v video.mp4 -s scripts.json` |
| `diagnose` | 系统诊断 | `cli diagnose` |

### 5.2 generate 命令

```bash
python -m video_gen.cli generate -t "视频标题" -s scripts.json [选项]

选项:
  -o, --output DIR    输出目录 (默认: ./output)
  --no-audio          跳过音频生成
  --no-images         跳过图片生成
```

### 5.3 subtitles 命令

```bash
python -m video_gen.cli subtitles -v video.mp4 -s scripts.json [选项]

选项:
  -o, --output FILE   输出视频路径 (默认: 自动生成)
  --format srt|ass    字幕格式 (默认: srt)
  --font-size SIZE    字体大小 (默认: 36)
  --dry-run           仅生成字幕文件，不嵌入视频
```

## 六、优化工作流（Python 编程接口）

### 6.1 一键生成

```python
from video_gen.workflow import OptimizedWorkflow

# 创建工作流实例
workflow = OptimizedWorkflow()

# 一键生成
result = workflow.quick_generate(
    script_path="scripts.json",
    title="我的视频",
    output_dir="./output"
)

# 处理结果
if result["success"]:
    print(f"视频: {result['video_path']}")
    print(f"目录: {result['output_dir']}")
else:
    print(f"错误: {result['errors']}")
```

### 6.2 带进度回调

```python
def progress_callback(current, total, message):
    print(f"[{current}/{total}] {message}")

result = workflow.quick_generate(
    script_path="scripts.json",
    title="我的视频",
    progress_callback=progress_callback
)
```

### 6.3 分步执行

```python
# 只执行验证和准备步骤
result = workflow.step_generate(
    script_path="scripts.json",
    title="我的视频",
    steps=["validate", "prepare"]
)

# 只合成视频（假设已有音频和图片）
result = workflow.quick_generate(
    script_path="scripts.json",
    title="我的视频",
    output_dir="output/202608/wo_de_shi_pin",
    progress_callback=progress_callback
)
```

### 6.4 错误容忍模式

```python
from video_gen.workflow import WorkflowConfig

config = WorkflowConfig(
    stop_on_error=False,      # 默认：错误时继续
    create_placeholder=True,  # 创建占位图
    skip_audio=False,
    skip_images=False,
    skip_video=False
)

workflow = OptimizedWorkflow(config)
result = workflow.quick_generate("scripts.json", "我的视频")
```

## 七、常见问题与解决方案

### 7.1 GPU 编码器错误

**问题**：`Cannot load nvcuda.dll` 或 `h264_nvenc 编码失败`

**原因**：系统检测到 NVIDIA 显卡但 CUDA 驱动不完整，或 GPU 编码器运行时不可用。

**解决方案**：
- 系统已自动修复此问题，会自动回退到 CPU 编码（libx264）
- 如需手动指定编码器，修改 `video_gen/video/encoder.py` 中的 `gpu_encoders` 列表
- 或卸载 NVIDIA 驱动后重新安装最新版

验证编码器状态：
```bash
python -m video_gen.cli diagnose
```

### 7.2 FFmpeg 未找到

**问题**：`ffmpeg` 命令执行失败

**解决方案**：
1. 下载 FFmpeg: https://ffmpeg.org/download.html
2. 将 `ffmpeg.exe` 和 `ffprobe.exe` 所在目录添加到系统 PATH
3. 重启命令行后验证：`ffmpeg -version`

### 7.3 字幕生成失败

**问题**：字幕没有出现在视频中

**检查步骤**：
1. 确认脚本中有 `text` 字段
2. 使用 dry-run 模式检查字幕文件内容：
   ```bash
   python -m video_gen.cli subtitles -v video.mp4 -s scripts.json --dry-run
   ```
3. 检查字幕文件是否生成成功
4. 确认 FFmpeg 支持字幕滤镜

### 7.4 音频生成超时

**问题**：`edge-tts` 生成音频超时

**原因**：文本过长时，一次性生成可能超时（默认 5 分钟限制）

**解决方案**：
- 系统会自动尝试分段生成音频
- 建议将脚本文本控制在 2000 字符以内
- 如果频繁超时，可以修改 `audio/generator.py` 中的超时时间

### 7.5 图片生成失败

**问题**：AI 图片生成 API 返回错误

**原因**：API 频率限制、网络问题或 API 服务不可用

**解决方案**：
- 系统会自动重试 3 次，失败后创建占位图
- 增加 API 调用间隔（修改 `image/api_client.py` 中的 `min_interval`）
- 检查网络连接

### 7.6 输出视频损坏

**问题**：生成的视频无法播放

**解决方案**：
1. 检查输出目录中是否有完整的 MP4 文件
2. 尝试使用字幕导入器为已有视频添加字幕：
   ```bash
   python video_gen/subtitle_importer.py -v output.mp4 -s scripts.json
   ```
3. 使用诊断工具检查环境：
   ```bash
   python -m video_gen.cli diagnose
   ```

## 八、性能优化建议

### 8.1 编码性能

- **CPU 编码**（默认）：在 GPU 编码器不可用时自动使用，稳定性最高
- 编码参数可在 `video_gen/config.py` 的 `VideoEncodingConfig` 中调整：
  - `crf`: 质量控制（18-28，越低质量越好，默认 23）
  - `preset`: 编码速度（ultrafast/fast/medium/slow，默认 medium）

### 8.2 图片生成

- API 调用间隔可在 `image/api_client.py` 中调整：
  - `min_interval`: 最小调用间隔（默认 3 秒）
  - `max_interval`: 最大调用间隔（默认 15 秒）
- 增加间隔可降低 API 频率限制风险，但会延长总生成时间

### 8.3 视频合成

- 视频分辨率在 `image/generator.py` 中配置（默认 1080x1920 竖屏）
- 图片数量越多，合成时间越长；建议每场景 1 张图片
